05 / Method

Reproducible, not vibes

Every number on this page is regenerated from the raw payloads by one script.

The script

Stdlib-only Python. Loads the three captured payloads, checks each documented promise, and computes the revenue scenarios.

python analysis/reconcile.py

The output

Findings, severity, the worst-one rationale, four revenue scenarios and the can’t-tell-from-this-data list — written to report.json.

analysis/report.json

The inputs

Untouched candidate-pack files: the docs, the ticket, and the three API responses. Nothing was cleaned up before auditing.
